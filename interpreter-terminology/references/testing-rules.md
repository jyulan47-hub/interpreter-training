# 记忆测试、口译评价、掌握度与智能复习（testing-rules.md）

本文件规定：**测试题型、口译评价维度、掌握度档位、错误记录、智能复习、场景口译流程**。测试的一切原材料来自个人术语库。

---

## 1. 测试题型（按需选用其一或组合）

| 题型 | 出题方式 |
|---|---|
| 1. 源语 → 目标语 | 给 `source_term`，用户说 `target_term` |
| 2. 目标语 → 源语 | 给 `target_term`，用户用源语/母语解释 |
| 3. 定义 → 术语 | 给专业定义，用户说术语 |
| 4. 术语 → 定义 | 给术语，用户解释 |
| 5. 完形填空 | 给语境句子（真实语料或明确标注的 AI 例句），用户填术语 |
| 6. 搭配测试 | 测常见专业搭配（collocations） |
| 7. 易混淆术语 | 比较近义词、上下位词、易误译词（`conflict`/`synonyms`/`variants`） |
| 8. 场景测试 | 模拟会议/谈判/发布会，见 §5 |

语言方向始终按词条的 `source/target/learning_language` 出题（R1），不额外插入第三种语言。

---

## 2. 口译评价维度

场景口译不能只判"词对不对"。按以下 8 项评价（每项可给分级评语）：
1. 术语准确性
2. 语言方向
3. 专业性
4. 语域（正式/口语/行业习惯）
5. 搭配
6. 信息完整度
7. 表达自然度
8. 是否符合真实口译场景

**尤其关注**：用户能否在真实口译中**快速调用**术语（速度与流畅度），而非仅书面正确。

---

## 3. 掌握度（mastery, 0–100）

| 范围 | 档位 |
|---|---|
| 0–20 | 陌生 |
| 21–40 | 见过 |
| 41–60 | 基本认识 |
| 61–80 | 能够回忆 |
| 81–90 | 熟练 |
| 91–100 | 稳定调用 |

每次测试后更新：`mastery`、`error_count`、`last_reviewed`、`next_review`。

---

## 4. 错误记录

每次测试记录结构化错误：

```json
{
  "term_id": "",
  "user_answer": "",
  "correct_answer": "",
  "error_type": "",
  "timestamp": ""
}
```

`error_type` 至少包括：
- 不认识
- 记错
- 拼写错误
- 语言方向错误
- 近义词混淆
- 搭配错误
- 语域错误
- 直译
- 专业含义错误

---

## 5. 场景口译训练流程

例："根据我的人工智能监管术语库，做一套中法会议口译训练。"

1. 分析场景（议题、机构、人物、语域）。
2. 从个人术语库检索相关术语（R6）。
3. 准备背景（如会议议题梗概）。
4. 生成口译材料（按 source/target 方向）。
5. 分段口译（逐段给源语，用户回译）
6. 记录错误到错误记录。
7. 按 §2 评价术语调用。
8. 更新掌握度 + `next_review`。
9. 据此生成后续复习内容（见 §6）。

---

## 6. 智能复习（非随机抽题）

优先抽取以下术语：
- 低掌握度（mastery 低）
- 近期出错（`error_count` 上升 / 最近错误）
- 高频术语（P1/P2，与 topic 相关）
- 容易混淆（conflict / 近义词组）
- 近期口译任务相关

**重点覆盖**："看起来认识、但实际口译时想不起来"的词（一般落在「见过/基本认识/能够回忆」区间且近期被用到）。

---

## 7. 测试报告

测试结束后，按 templates/terminology-report.md 中的测试报告结构输出：
- 得分与掌握度变化
- 错误清单（按 error_type 归类）
- 推荐复习清单
- 薄弱项与下次训练建议
