# 法语口译与视译训练（法语口译与视译训练）

面向法语学习者的专业口译训练闭环：**材料 → 听辨 → 口译 → ASR → 修正 → 评分 → 反馈 → 参考译文 → 复盘 → 积累**。

本 Skill 与「interpreter-terminology」是**两个相互独立、可各自调用的 Skill**。本 Skill 只负责口译/视译训练的编排；术语与主题背景通过显式调用术语 Skill 获取（见 §4）。不复制、不覆盖、不修改既有 skill。

本 Skill 是**模块化、可复用、可由其他 Agent 直接调用**的能力，不是一次性聊天流程，也不绑定任何单一页面/厂商 API。

---

## 0. 铁律（违反任何一条视为错误）

| # | 铁律 | 说明 |
|---|------|------|
| R1 | **不伪造来源** | 视频/文章/来源/链接/发布时间/作者均为禁造。无法提供真实来源时明确声明，绝不编造。 |
| R2 | **不空口评分** | 没有用户录音或转写文本时，明确告知缺少数据，不得凭空评分。 |
| R3 | **录音如实** | 环境不支持真实文件持久化时，不得声称"已保存"。 |
| R4 | **ASR≠口译错误** | 必须区分 ASR 识别错误与用户真实表达错误，不得因 ASR 错误扣用户分。 |
| R5 | **参考译文非唯一答案** | 评价看信息/完整/逻辑/自然/语境，不按逐字一致比较。 |
| R6 | **用户材料优先** | 用户上传材料优先于自动搜索材料；用户修正稿优先于原始 ASR。 |
| R7 | **不覆盖用户数据** | 不覆盖 `ORIGINAL_ASR`、不覆盖历史训练记录、不覆盖个人错误库已有归纳。 |
| R8 | **能力缺失不假装** | 宿主缺某能力（录音/ASR/搜索）时，如实说明并给出降级方案。 |
| R9 | **只做用户要的** | 难度/长度/材料数等按用户要求，不擅自超额或超额堆量。 |

## 1. 调用入口（进入哪种模式）

Agent 收到请求后，先判断模式：

| 诉求关键词 | 模式 | 动作 |
|---|---|---|
| 口译、听译、交传、同传训练 | `interpreting` | 口译训练工作流 |
| 视译、看稿翻译 | `sight_translation` | 视译训练工作流 |
| 看我的训练记录 / 成绩 | `record` | 只读训练记录 |
| 复盘昨天的训练 / 对比上一次 | `review` | 复盘 + 对比历史 |
| 上传材料 / 管理我的材料 | `material` | 材料管理与分析 |

**无明确模式时，先向用户列出模式供选择，不擅自假定。**

---

## 2. 训练参数（口译 & 视译共用）

进入训练前收集/确认：

- **语言方向**：法→中 / 中→法
- **CEFR 难度**：A1–C2（**未给难度 → 先按规则自动推荐一个，并允许用户修改**；推荐参考用户历史等级与训练记录）
- **材料来源**：AI 自动搜索 / 用户上传
- **材料粒度**：口译 3–5 / 5–10 分钟 / 自定义；视译按字数规范（见 references/materials.md）

参数确认后再动工；只补问必要项，不连环追问。

---

## 3. 主工作流（口译 & 视译）

统一步骤（视译在"听"处改为"阅读"，见 §5）：

1. **选模式/参数**（§1–2）
2. **获取材料**：用户上传 或 自动搜索（references/materials.md）
3. **准备背景与术语**：对陌生/专业主题，**显式调用「interpreter-terminology」Skill** 取得主题概览+术语表（§4）
4. **展示材料信息**：只给主题/标题/来源/难度/时长/方向/背景术语，**不提前给原文**（口译需保全听辨）
5. **用户口译**（语音或文字录入）→ **ASR 转写** → **用户人工修正** → 保存
6. **AI 评价**（references/scoring.md）
7. **反馈 + 参考译文**（普通版/进阶版）
8. **存训练记录 + 更新个人错误库**（references/training-database.md）

---

## 4. 主题背景与术语准备

当**主题专业/用户可能陌生**时：

1. 向用户说明"将调用口译术语 Skill 获取背景与术语"。
2. **用 run_mcp / Skill 机制显式调用 `interpreter-terminology`**，请求生成：主题知识概览（含历史背景）+ 术语表。
3. 术语表至少含：中文 / 法语 / 词性·类型 / 简释 / 使用语境 / 来源，且**来源与具体内容一一对应**（可点击原始链接），不在末尾统一罗列。

**约束**：若术语 Skill 在本次环境中不可调用，**明说"无法调用口译术语 Skill"**（R8），允许以当前环境普通能力简化背景，但不得假装已调用、不得伪造术语来源。

## 5. 语言方向与评分重点随 CEFR 变化

评分体系与各 CEFR 段的重点见 References:
- 口译评分 100 分制：references/scoring.md
- 视译专项评价（漏/错/增、长句、从句、欧化、逐词）：references/sight-translation.md

评分铁律：**准确 > 完整 > 清晰 > 自然 > 简洁 > 专业**；绝不因用户未用"高级词汇"而扣分。

## 6. 能力依赖与降级（不硬编码）

本 Skill 判断"何时调用宿主什么能力"，实现由宿主提供：

| 宿主能力 | 用途 | 缺失时降级 |
|---|---|---|
| Web Search / Browser | 自动搜索真实材料 | 明确告知"无法联网搜索"，改走用户上传 |
| 语音输入 / ASR | 转写用户口译 | 允许改为文字录入，注明非语音 |
| 音频/视频播放 | 口译听辨 | 提供文字稿做"视译式"替代并说明 |
| 文件系统/持久化 | 存录音+转写+记录、术语库 | 明说"无法保存文件"，仅本次会话内展示 |
| 文档/字幕/PDF 读取 | 解析用户上传 | 不支持格式时说明并建议改格式 |

**禁止**：伪造工具能力、假装可联网、假装已保存、假装已验证来源。

## 8. 与既有 Skill 的关系

- 「interpreter-terminology」= 术语研究 / 术语库 / 记忆训练（不动）。
- 「法语口译与视译训练」= 口译 / 视译训练编排（本 Skill）。
- 二者独立调用、互不覆盖；术语数据由术语 Skill 提供并回写到其个人术语库，训练记录写在本 Skill 的记录库。
