# 法语口译学习 Skill 合集

一套面向法语学习者的**专业口译术语研究 + 口译/视译训练**解决方案，可独立使用，也可通过统一入口闭环学习。

支持方向：**法 ↔ 中**（也可按需配置中/英/法等任意方向）。

---

## 内容概览

本合集包含三个相互独立、可协作的 Skill：

| Skill 目录 | 名称 | 定位 |
|---|---|---|
| `interpreter-terminology` | 口译术语研究 | 译前准备：主题概览、术语库、权威来源核验、记忆测试 |
| `french-interpretation-training` | 法语口译与视译训练 | 口译/视译训练：材料、听辨/视读、ASR、评分、反馈、错误库 |
| `french-interpretation-learning` | 法语口译学习（统一入口） | 封装以上两者，提供统一学习流程与数据管理 |

> `french-interpretation-learning` 是总入口，**不重复实现**前两者的专业逻辑，只做编排与记录保存。即插即用、可单独安装任一 Skill。

---

## 能力模块

### 1. 口译术语研究（interpreter-terminology）

学习闭环：**研究 → 核验 → 入库 → 修改 → 积累 → 测试 → 发现薄弱项 → 复习 → 再口译 → 继续积累**

- 主题知识概览（背景/现状/机构/政策，逐条带来源）
- 专业术语研究，按 P1/P2/P3 优先级排序
- 权威来源核验（官方术语库、法规、机构文件），可点击原始链接
- 个人术语库管理（JSON），支持用户修订版本与 AI 候选并存
- 记忆测试与智能复习

### 2. 法语口译与视译训练（french-interpretation-training）

训练闭环：**材料 → 听辨 → 口译 → ASR → 修正 → 评分 → 反馈 → 参考译文 → 复盘 → 积累**

- 口译 / 视译两种模式
- 法→中、中→法双向
- CEFR（A1–C2）分层评分体系（100 分制）
- 自动评分 + 问题诊断 + 双版本参考译文（普通版 / 进阶版）
- 训练记录 + 个人错误库，支持复盘对比

### 3. 法语口译学习（统一入口）

- 首次使用引导 + 入口菜单
- 自动判断是否需要译前准备，并调用对应 Skill
- 学习记录统一保存、筛选
- 学习数据导入 / 导出（统一 `.md` 格式），多条记录用标记切分、可去重合并

## 设计原则

- **模块化**：三个 Skill 相互独立，可按需单独安装。
- **不重造逻辑**：统一入口只做编排，专业功能复用前两个 Skill。
- **不虚构/不伪造**：不伪造来源、评分、链接、保存结果；环境能力缺失时如实降级。
- **评分铁律**：准确 > 完整 > 清晰 > 自然 > 简洁 > 专业；不为"高级表达"扣分。
- **用户数据优先**：用户修正稿、历史记录、个人术语库永不被自动覆盖。

## 安装

将对应 Skill 目录放入宿主环境的 `skills/` 目录即可被识别。

## 使用示例（统一入口）

```
「Use Skill: french-interpretation-learning」
  ├─ 译前准备 → 选择主题 + 语言方向 → 自动调用术语研究 Skill
  ├─ 口译练习 / 视译练习 → 上传或生成材料 → 训练 → 评分反馈
  ├─ 学习记录 / 复盘
  └─ 导入学习数据 / 导出学习数据（.md）
```

## 支持的语言方向

默认面向 **法语 ↔ 中文**，但术语研究 Skill 的语言字段全部动态化，可扩展至英、法、西、德等任意方向。
